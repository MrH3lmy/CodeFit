# Bundled typography

Space Grotesk and Inter are bundled locally for offline rendering, under their included SIL Open Font License files. No font request occurs at runtime. License text uses LF line endings with trailing whitespace removed; the legal wording is unchanged.

Downloaded 2026-10-20 from the official Google Fonts repository:

- [Space Grotesk variable TTF](https://github.com/google/fonts/blob/main/ofl/spacegrotesk/SpaceGrotesk%5Bwght%5D.ttf), with [OFL](spacegrotesk-OFL.txt).
- [Inter variable TTF](https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf), with [OFL](inter-OFL.txt).
