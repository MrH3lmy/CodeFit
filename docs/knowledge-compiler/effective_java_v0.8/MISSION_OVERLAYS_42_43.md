# Eight original mission-overlay designs (not executable graders)

These **replace** existing draft slots EJ4-042-01 through EJ4-043-04, rather than adding new unique missions.

| ID | Stage | New original assessment brief | Core rubric |
|---|---|---|---|
| EJ8-042-Q1 | Predict | Compare lambda and anonymous callback receiver identity; then reassign a captured local. | Lexical `this`, anonymous receiver, effectively-final rejection. |
| EJ8-042-Q2 | Debug | Repair a raw-type routing comparator and a long stateful retry lambda. | Restore generic inference; extract named complex behavior. |
| EJ8-042-Q3 | Build | Implement typed event predicates and a separately named stateful rule. | Correct target typing, deterministic edge cases, clear ownership. |
| EJ8-042-Q4 | Defend | Choose lambda, anonymous class or nested class for a versioned callback. | Type limitations, `this` differences, serialization risk. |
| EJ8-043-Q1 | Predict | Classify reference forms and infer functional input arity. | Static/bound/unbound/constructor distinctions. |
| EJ8-043-Q2 | Debug | A bound reference breaks service hot-swapping; explain and repair. | Early binding versus deferred lookup, replacement test. |
| EJ8-043-Q3 | Build | Create typed parsing, trimming, event construction and counter aggregation pipeline. | Typed targets, invalid input, empty input. |
| EJ8-043-Q4 | Defend | Compare a named method reference with a readable business lambda. | Clarity, overload risk, meaningful argument names. |

Every mission requires a separate held-out learner grader and independent technical review before use for scoring or mastery. No CodeFit runtime changes.
